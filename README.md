# datPiff Preview (Next.js)

A mobile-friendly Next.js recreation of the classic DatPiff mixtape experience.

## Run locally

```bash
cd datpiff-preview
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Mobile features

- 2-column grid on phones, expands on larger screens
- Large touch targets (44px+ buttons)
- Sticky header with horizontal-scrolling nav
- Featured section stacks vertically on small screens
- Responsive search and logo sizing
- Viewport meta for proper mobile scaling

All cover art is in `public/covers/`.
